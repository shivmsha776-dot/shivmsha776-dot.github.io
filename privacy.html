Privacy policy

Last updated: 4 November 2026

Channel Hub is a private desktop tool that runs on its owner's own computer. It is used only by that owner, to upload the owner's videos to the owner's own YouTube channels.

YouTube API Services

Channel Hub uses YouTube API Services. By using Channel Hub you agree to be bound by the YouTube Terms of Service. Google's handling of personal information is described in the Google Privacy Policy.

What information is accessed

With permission given through Google sign-in (OAuth), Channel Hub accesses through the YouTube Data API:

  • the signed-in YouTube channel's name, ID and picture, and the email address of the Google account;
  • the list of videos on that channel: titles, descriptions, tags, category, privacy and schedule settings, original upload file names and playlists.

How it is used

  • To upload new videos to the owner's channel, set their thumbnails and add them to playlists.
  • To avoid uploading the same file twice (by comparing file names with videos already on the channel).
  • To reuse the title and description of an earlier part of the same story for its next part.

The information is not used for advertising, profiling or any other purpose.

Storage and sharing

Sign-in tokens and the video information above are stored only on the owner's computer, in the application's own folder. Nothing is sent to any server other than Google's YouTube services. No information is sold, shared with or disclosed to any third party.

Channel Hub does not use cookies, and does not place or read any information on users' devices or browsers other than its own local files.

Keeping information fresh and deleting it

  • Stored video information is refreshed from YouTube every few hours.
  • Disconnecting a channel in Channel Hub immediately deletes its sign-in token and all stored information about that channel.
  • If a channel's access is revoked and its information can no longer be refreshed, the stored information for that channel is deleted automatically within 30 days.
  • Deleting the application folder deletes all stored information.

Revoking access

Access can be removed at any time on the Google security settings page: https://security.google.com/settings/security/permissions (choose "Channel Hub", then "Remove access").

Changes
